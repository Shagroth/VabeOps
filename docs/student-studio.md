# Студия участника — что изменилось (ветка `feature/student-studio`)

Цель: к старту первой группы (5–6 человек) участник заходит на платформу и
видит в одном месте курс, лабораторию, домашнюю работу, сдачу, фидбек и
обсуждение недели.

## Что сделано

| Область | Изменение |
|---|---|
| Публичный demo-курс | Открыты только модули 1–2 (`src/content/demo-access.ts`). `/demo-course/3…5` показывают обложку модуля и блок «для участников пилота»; уроки и ТЗ домашки этих модулей не попадают ни в HTML, ни в клиентский бандл (проверено по `.next` после сборки). Страницы 3–5 — `noindex`. |
| Неделя когорты ↔ контент курса | Новое поле `Module.courseModuleNumber Int?` (миграция `0003`). Если задано, `/modules/[id]` рендерит интерактивный урок, лабораторию и ТЗ домашки из `src/content`, ниже — сдача, фидбек, анкета и обсуждение. Markdown-поля недели остаются как «Заметки автора к неделе». |
| Лаборатория → сдача | Кнопка «Перенести в сдачу ↓» на шаге артефакта кладёт собранный Markdown в поле «Результат» формы сдачи (`src/lib/artifact-bridge.ts`). Лимит поля поднят до 12 000 символов, общий для клиента и сервера. |
| Админка | «Создать недостающие недели из программы» (5 недель, открыта только 1-я, повторный клик безопасен); кнопки «Открыть/Закрыть» у каждой недели; выбор модуля курса в форме недели; блок «Участники»: зачислить по email + имя + уровень, отчислить, сделать/снять ментора. В «Заявках» у принятой заявки — «Зачислить» в выбранную когорту. |
| Приватность | Участники видят друг друга по имени, не по email (Поток, обсуждения, «поделились решением», фидбек). В клиентские компоненты больше не уходят целые строки `User`. Имя редактируется в профиле «Потока»; на обзоре — подсказка, если имени нет. |
| Обзор | «Следующий шаг» с приоритетом: доработка по фидбеку → первая открытая несданная неделя → «все сданы, следующей откроется неделя N» (`src/lib/next-step.ts`). |

## Деплой

- Схема изменилась аддитивно (одна nullable-колонка). Pre-deploy на Railway —
  `npx prisma db push` — применит её без потери данных.
- Новых переменных окружения нет.

## Запуск группы — чек-лист автора

1. `/admin` → создать когорту → «Создать недостающие недели из программы».
2. Зачислить себя (чтобы видеть неделю глазами участника) и участников по email.
3. Добавить созвоны (kickoff/midpoint/final).
4. Открывать недели кнопкой «Открыть» по расписанию.

## Не сделано (следующие шаги)

- Email-уведомления (новая сдача → автору, фидбек → участнику).
- Общая очередь проверки по всем неделям и оценка по рубрике (20 баллов).
- Ментор (роль MENTOR) может ставить фидбек через server action, но экран
  проверки по-прежнему только в `/admin` (ADMIN).
- Прогресс урока/лаборатории хранится в localStorage браузера, не на сервере.
